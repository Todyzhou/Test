# 话题社区 - 暗黑主题社交平台

一个参考微博功能和布局设计的暗黑色调话题社区平台，提供完整的社交媒体体验。

## ✨ 功能特性

### 🌙 暗黑主题设计
- 现代化的暗黑色调界面
- 高对比度文字显示
- 优雅的阴影和动画效果
- 完整的设计系统和组件库

### 📱 核心功能
- **用户认证系统** - 登录、注册、密码重置
- **动态发布** - 支持文本、话题标签、@提及功能
- **话题系统** - 话题页面、热门话题推荐
- **用户互动** - 点赞、评论、转发、关注
- **个人主页** - 用户资料、动态展示、统计数据
- **搜索功能** - 用户、话题、内容搜索
- **消息通知** - 实时通知系统

### 📱 响应式设计
- 完美适配桌面端、平板和手机
- 移动端优化的触摸交互
- 自适应布局和组件

## 🎨 设计系统

### 色彩规范
- **主背景**: `#0f1419` - 深邃的夜空色
- **卡片背景**: `#1e2328` - 温和的深灰色
- **强调色**: `#1d9bf0` - 现代蓝色
- **文字颜色**: `#ffffff` / `#8b949e` / `#6e7681`

### 组件库
- 按钮组件 (主要、次要、幽灵、危险)
- 卡片组件 (标准、悬停效果)
- 输入框组件 (标准、错误状态)
- 头像组件 (多种尺寸)
- 徽章组件 (通知、状态)
- 模态框组件
- 下拉菜单组件

## 🛠️ 技术栈

- **前端框架**: 原生 HTML5 + CSS3 + JavaScript (ES6+)
- **样式系统**: CSS 自定义属性 + Flexbox + Grid
- **图标库**: Font Awesome 6.0
- **数据存储**: LocalStorage (模拟后端)
- **响应式**: Mobile-First 设计方法
- **动画**: CSS Transitions + Keyframes

## 📱 页面功能

### 🏠 社区主页 (`community.html`)
- 顶部导航栏 (搜索、通知、用户菜单)
- 左侧导航菜单 (首页、发现、通知等)
- 动态发布器 (文本、话题、@提及)
- 时间线动态流 (无限滚动)
- 右侧推荐区域 (热门话题、推荐用户)

### 🏷️ 话题页面 (`pages/topic.html`)
- 话题头部信息 (标题、描述、统计)
- 话题关注功能
- 内容标签页 (最新、热门、媒体)
- 话题相关动态流

### 👤 个人主页 (`pages/profile.html`)
- 用户资料展示 (头像、简介、统计)
- 关注/取消关注功能
- 内容标签页 (动态、回复、媒体、喜欢)
- 用户动态时间线
